Data Science Professional Portfolio – SQL Project

A MySQL-based relational database project designed to store and analyze a fictional data science professional's personal information, education, skills, work experience, projects, certifications, tools, and social profiles.

The project uses SQL queries to perform data retrieval, filtering, aggregation, joins, subqueries, CTEs, CASE statements, and window functions to generate insights about skill proficiency, experience, project domains, tools used, certifications, and professional background.

The project demonstrates practical SQL skills in database design, relational data management, data analysis, and extracting meaningful insights from structured professional data.
